# 🪷 Lotus & Line — Boutique Movement & Wellness Studio

> A refined, minimal, and fully customized WordPress website built for a luxury Reformer Pilates and holistic wellness studio.

---

## 📌 Project Overview

**Lotus & Line** is a boutique wellness studio specializing in Reformer Pilates, Clinical Pilates, Therapeutic Massage, and Body Treatments. The objective of this project was to design and develop a serene, high-end digital experience that reflects the studio's calming physical environment while offering seamless navigation for prospective and returning clients.

The entire site was built from scratch in **WordPress** using the **Gutenberg Block Editor** and **Spectra**, focusing on custom styling, lightweight design, and clean user experience (UX) without relying on heavy third-party page builders or paid plugins.

---

## ✨ Key Features & Page Highlights

* **Home Page:** Impactful hero banner with soft gradient overlays, session category breakdown, pricing/membership cards, client testimonials, and clear call-to-action (CTA) buttons.
* **About (Our Philosophy):** Storytelling layout featuring custom oval image masks, studio philosophy breakdown, and instructor showcase.
* **Services:** A clean 4-pillar grid outlining class types, duration, and target benefits, paired with an interactive **FAQ Accordion**.
* **Contact:** Functional contact form integrated with studio operating hours, location details, and field validation.
* **Client Portal (Login):** A custom-styled login interface housed within an elegant card layout featuring watermarked brand assets.
* **Privacy Policy:** Full compliance page linked in the footer to ensure standard web accessibility and data protection practices.

---

## 🛠️ Technical Stack & Tools

* **CMS:** WordPress (Full Site Editing / Gutenberg Editor)
* **Block Enhancements:** Spectra Blocks
* **Styling:** Custom CSS, Tailored Typography (Serif Headers + Clean Sans-serif Body)
* **Accessibility & SEO:** Descriptive Alt Text for all media assets, structured semantic HTML, and mobile-first responsive layout.

---

## 🎨 Design System & Palette

* **Primary Nude / Beige:** `#F4EBE2` *(Warm, soft background)*
* **Card Surface Cream:** `#FBF8F5` *(Elevated contrast for cards and modals)*
* **Accent Olive Green:** `#8A9A86` *(Calm CTA buttons with pill-shaped rounded borders)*
* **Typography:** Serif for headings (luxury, high-end aesthetic) paired with clean Sans-Serif for body text.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Import the WordPress database/XML export into your local environment (e.g., **LocalWP**, **XAMPP**).
3. Ensure the active theme is configured with Gutenberg Block support.
4. Access `http://localhost/lotus-line` in your browser.

# 🇧🇷 🪷 Lotus & Line — Estúdio Boutique de Movimento e Bem-Estar

> Um site em WordPress elegante, minimalista e 100% personalizado, desenvolvido para um estúdio de luxo focado em Reformer Pilates e terapias holísticas.

---

## BR 📌 Visão Geral do Projeto

O **Lotus & Line** é um estúdio boutique especializado em Reformer Pilates, Pilates Clínico, Massagem Terapêutica e Tratamentos Corporais. O objetivo principal deste projeto foi planejar, estruturar e desenvolver uma experiência digital serena e sofisticada, alinhada à identidade visual e à atmosfera física do estúdio.

O site foi construído do zero no **WordPress** utilizando o editor nativo de blocos (**Gutenberg**) e a extensão **Spectra**, priorizando leveza, alto desempenho, responsividade e estética refinada, sem a necessidade de plugins pagos ou construtores pesados.

---

## ✨ Destaques das Páginas & Funcionalidades

* **Home Page:** Banner principal com gradiente suave, seção de modalidades de aulas, tabela visual de planos/mensalidades em cards, depoimentos e chamadas para ação (CTAs) estratégicas.
* **About (Nossa Filosofia):** Design focado em storytelling com imagens estilizadas em máscaras ovais e apresentação dos pilares do estúdio.
* **Services:** Grade organizada em 4 pilares contendo descrição das sessões, duração e objetivos, além de uma seção interativa de **Perguntas Frequentes (FAQ)**.
* **Contact:** Formulário de contato funcional com validação de campos, integrado com informações de funcionamento e endereço do estúdio.
* **Client Portal (Login):** Interface de login customizada dentro de um card centralizado com a marca d'água da logo ao fundo.
* **Privacy Policy:** Página completa de políticas de privacidade vinculada no rodapé para conformidade com boas práticas de navegação e LGPD.

---

## 🛠️ Tecnologias Utilizadas

* **CMS:** WordPress (Full Site Editing / Editor Gutenberg)
* **Blocos & Componentes:** Spectra Blocks
* **Estilização:** CSS Customizado e sistema de cores padronizado
* **Acessibilidade & SEO:** Alt Text em inglês aplicado em todas as imagens, HTML semântico e layout responsivo.

---

## 🎨 Sistema de Design & Paleta de Cores

* **Fundo Nude Principal:** `#F4EBE2` *(Atmosfera acolhedora e relaxante)*
* **Creme para Cards:** `#FBF8F5` *(Contraste suave para blocos de destaques)*
* **Verde Oliva (Acento):** `#8A9A86` *(Botões arredondados em formato de pílula)*
* **Tipografia:** Tipografia Serifada nos títulos (sofisticação) combinada com Sans-Serif limpa para o corpo de texto.
